# SniffKitty

ESP32-based odor monitoring system for pet odor monitoring and environmental sensing.

## Overview

SniffKitty is a hardware-software project designed to monitor odor levels around pet environments using gas sensors and embedded systems.

The system integrates sensors with an ESP32 microcontroller to collect environmental data and evaluate odor conditions in real time.

## Features

- ESP32-based embedded system
- Gas sensor integration
- Real-time data collection
- Hardware debugging and testing
- Sensor calibration and validation

## Hardware

- ESP32
- MQ135 Gas Sensor
- Power Supply Module
